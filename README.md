# Gambit-Goblins

A fully autonomous, 3D-printed chess playing robot powered by an Arduino Uno Q.
Created by the ingenious team the Gambit Goblins.

## Overview

The **Gambit Goblins** combines computer science with some parts of engineering to create a physical opponent for chess players. Using a **SCARA arm**, The robot moves pieces across a standard chessboard based on moves calculated by a chess engine.
